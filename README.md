# DinoLand Naya 🦖✨

Website 3D interaktif bertema dinosaurus spesial untuk anak tercinta, **Naya**!

## Fitur Unggulan
- **Dunia 3D Interaktif (Three.js)**: 5 karakter dinosaurus lucu (Rexy Si T-Rex, Longi Si Brachiosaurus, Trike Si Triceratops, Spiky Si Stegosaurus, dan Pteri Si Pterodactyl yang terbang di angkasa).
- **Interaksi Sentuh & Klik**: Klik/sentuh dinosaurus apa pun untuk melihatnya melompat, mengaum, dan mengeluarkan balon kata sapaan seru.
- **Efek Suara & Musik Sintesis (Web Audio API)**: Musik latar ceria dan sound effects (auman, suara lompat, kunyahan makan) 100% sintetis tanpa file eksternal.
- **Beri Makan Dinosaurus**: Lempar semangka, apel, dan dedaunan segar untuk dimakan dinosaurus dengan efek konfeti!
- **Pesta Disko Dino**: Mode lampu disko warna-warni berputar dengan tarian dinosaurus.
- **Mode Siang & Malam**: Transisi dari suasana padang rumput cerah ke malam berbintang dengan gunung berapi menyala.
- **Tombol Foto (Screenshot)**: Simpan momen petualangan Naya ke dalam gambar PNG.
- **Ringan & Cepat**: Berjalan di atas kontainer Nginx Alpine ultra-ringan (~10MB RAM).
